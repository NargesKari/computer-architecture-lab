# computer-architecture-lab

Computer Architecture lab assignments built and simulated in Proteus, progressing from individual combinational circuits to a microprogrammed processor. Group coursework, not solo work.

## What's in here

- **Lab 01-04** — combinational building blocks: a BCD adder, a carry-select adder, an 8-bit multiplier, and a floating-point adder.
- **Lab 06** — an ALU built from the earlier combinational blocks.
- **Lab 07** — an instruction memory (IMEM) loaded with a Fibonacci program in binary.
- **Lab 09** — a microprogrammed control unit: microinstruction memory plus multiple test programs (Fibonacci, a sum-to-64 loop) run against it.

Each lab folder has its Proteus project (`.pdsprj`) and a written report (`report.pdf`); `Lab-Manual.pdf` is the course's lab manual.

## Tech stack

Proteus (schematic capture + simulation), hand-assembled/binary program and microcode images.

## Running it

Open the `.pdsprj` file for a given lab in Proteus (ISIS) to view and simulate the circuit; each report PDF documents the design and test results for that lab.
